# Dieta Conte RC1

PWA mobile-first per la Settimana 1 (10–16 agosto 2026).

## Installazione GitHub Pages
1. Carica tutti i file contenuti nella cartella nella root della repository.
2. Commit su `main`.
3. Settings → Pages → Deploy from a branch → `main` / root.
4. Apri il sito da Chrome su Android e usa "Aggiungi a schermata Home" / "Installa app".

## Dati
Peso, spunte della spesa, pasti completati e attività vengono salvati localmente nel browser del dispositivo.
Quindi non si sincronizzano automaticamente tra telefono e PC.
