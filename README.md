# Dieta Conte RC7 — Diario Pressorio

Base RC6 invariata nelle funzioni esistenti, con nuova sezione **Pressione**.

Novità RC7:
- diario pressorio con data/ora automatica;
- massima, minima, battiti, momento della giornata e nota;
- ultima misura, media del giorno e media degli ultimi 7 giorni;
- grafico indipendente di massima, minima e battiti;
- confronto peso **opzionale** tramite flag, su grafico separato;
- storico con eliminazione singola misura;
- esportazione CSV del diario;
- card rapida “Pressione oggi” nella Home;
- dati salvati localmente sul dispositivo;
- cache PWA aggiornata a RC7.

Per aggiornare su GitHub Pages: sostituire i file della RC precedente con quelli di questo pacchetto.
